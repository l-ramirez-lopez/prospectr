# A fast distance algorithm for a matrix and a vector written in C++

A fast distance algorithm for a matrix and a vector written in C++

## Usage

``` r
fastDistV(X,Y,method)
```

## Arguments

- X:

  a `matrix`

- Y:

  a `vector`

- method:

  a `string` with possible values "euclid", "cor", "cosine"

## Value

a distance `vector`
